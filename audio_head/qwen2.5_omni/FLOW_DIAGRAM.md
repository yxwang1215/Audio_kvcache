# 工作流程图解

## 完整流程概览

```
┌─────────────────────────────────────────────────────────────────┐
│                    1. 数据准备阶段                                │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
        ┌─────────────────────────────────────┐
        │  WhisperX JSON                      │
        │  - 单词列表                         │
        │  - 时间戳 (start_time, end_time)    │
        │  - 质量分数 (score > 0.95)          │
        └─────────────────────────────────────┘
                      │
                      ▼
        ┌─────────────────────────────────────┐
        │  时间戳 → 音频 Token 映射            │
        │  "hello": 0.5s-0.8s                 │
        │  → audio_token[50:80]               │
        └─────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    2. 模型生成阶段                                │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
        ┌─────────────────────────────────────┐
        │  输入: 音频 + Prompt                 │
        │  → Prefill 阶段                      │
        │  → Decode 阶段（生成文本）            │
        └─────────────────────────────────────┘
                      │
                      ▼
        ┌─────────────────────────────────────┐
        │  Hook 捕获注意力                     │
        │  每个 decode step:                  │
        │  - 生成一个 token                   │
        │  - 捕获所有 layer/head 的注意力      │
        └─────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    3. Token 对齐阶段                              │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
        ┌─────────────────────────────────────┐
        │  生成的 Token 序列                   │
        │  ["The", " quick", " brown", ...]   │
        └─────────────────────────────────────┘
                      │
                      ▼
        ┌─────────────────────────────────────┐
        │  Token → 单词对齐                     │
        │  策略:                                │
        │  1. 解码 token → 文本                │
        │  2. 累积文本直到匹配 WhisperX 单词    │
        │  3. 标记 token 属于哪个单词          │
        └─────────────────────────────────────┘
                      │
                      ▼
        ┌─────────────────────────────────────┐
        │  对齐结果                            │
        │  Token 0 → "The" (WordAlignment)    │
        │  Token 1 → "quick" (WordAlignment)   │
        │  Token 2 → "brown" (WordAlignment)   │
        │  ...                                 │
        └─────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                    4. 注意力分析阶段                              │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
    ┌───────────────────────────────────────────────────┐
    │  对于每个"高质量单词"的 token:                      │
    │  例如: 生成 "hello" 的 token                        │
    └───────────────────────────────────────────────────┘
                      │
        ┌─────────────┴─────────────┐
        │                           │
        ▼                           ▼
┌───────────────┐         ┌──────────────────┐
│ 目标区域定义   │         │  注意力权重分析    │
│               │         │                   │
│ word_audio_  │         │ 对于每个          │
│   indices =   │         │ layer/head:       │
│ {50,51,...,80}│         │                   │
│               │         │ 1. 计算 top-k     │
│ (对应"hello"   │         │    位置           │
│  的音频token)  │         │ 2. 统计命中数     │
└───────────────┘         │ 3. 计算权重和     │
                          └──────────────────┘
                                  │
                                  ▼
                    ┌─────────────────────────────┐
                    │  计算三个指标:               │
                    │                             │
                    │  S_hit = hits / K           │
                    │  S_attn = w_word / w_audio  │
                    │  S_cov = hits / |A(w_i)|    │
                    └─────────────────────────────┘
                                  │
                                  ▼
┌─────────────────────────────────────────────────────────────────┐
│                    5. Head 重要性评分                             │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
        ┌─────────────────────────────────────┐
        │  聚合所有单词 token 的统计             │
        │  对于每个 layer/head:                 │
        │  - 收集所有 token 的 S_hit, S_attn,   │
        │    S_cov                              │
        │  - 计算平均值                         │
        └─────────────────────────────────────┘
                      │
                      ▼
        ┌─────────────────────────────────────┐
        │  加权重要性分数                       │
        │  importance_score =                  │
        │    α·S_hit + β·S_attn + γ·S_cov     │
        │                                     │
        │  (默认: α=1.0, β=1.0, γ=1.0)        │
        └─────────────────────────────────────┘
                      │
                      ▼
        ┌─────────────────────────────────────┐
        │  排序并输出 Top Heads                 │
        │  - 按 importance_score 降序排序      │
        │  - 输出 Top 20 等重要 heads          │
        └─────────────────────────────────────┘
```

## 关键步骤详解

### Step 1: Token 对齐示例

```
生成的 Token 序列:
  ["The", " quick", " brown", " fox", " jumps"]

WhisperX 单词序列:
  ["The", "quick", "brown", "fox", "jumps"]

对齐过程:
┌─────────┬──────────┬──────────────┬─────────────┐
│ Token   │ 累积文本  │ 匹配单词      │ 对齐结果     │
├─────────┼──────────┼──────────────┼─────────────┤
│ "The"   │ "The"    │ "The" ✓      │ Token 0 →   │
│         │          │              │ Word 0      │
├─────────┼──────────┼──────────────┼─────────────┤
│ " quick"│ "The     │ "quick" ✓    │ Token 1 →   │
│         │ quick"   │              │ Word 1      │
├─────────┼──────────┼──────────────┼─────────────┤
│ " brown"│ "The     │ "brown" ✓    │ Token 2 →   │
│         │ quick    │              │ Word 2      │
│         │ brown"   │              │             │
└─────────┴──────────┴──────────────┴─────────────┘
```

### Step 2: 注意力分析示例

```
生成 Token: "hello" (step_idx = 5)
对应的 WordAlignment:
  - word: "hello"
  - audio_token_start: 50
  - audio_token_end: 80

对于 Layer 10, Head 5:
┌─────────────────────────────────────────────────┐
│ 注意力向量 (attn): [0.01, 0.02, ..., 0.15, ...]  │
│                    ↑     ↑              ↑        │
│                    位置0  位置1         位置50     │
└─────────────────────────────────────────────────┘
                      │
                      ▼
        计算 Top-K (K=32):
        topk_indices = [50, 51, 100, 101, ...]
                      ↑    ↑
                      命中目标区域！
                      │
                      ▼
        统计:
        - word_hits = 2  (50, 51 在 {50..80} 中)
        - S_hit = 2/32 = 0.0625
        - S_attn = sum(attn[50:80]) / sum(attn[audio])
        - S_cov = 2 / 31 = 0.0645  (目标区域有31个token)
```

### Step 3: 重要性评分示例

```
Layer 10, Head 5 在所有单词 token 上的表现:

Token 1 ("The"):   S_hit=0.05,  S_attn=0.10,  S_cov=0.08
Token 2 ("quick"): S_hit=0.08,  S_attn=0.15,  S_cov=0.12
Token 3 ("brown"): S_hit=0.06,  S_attn=0.12,  S_cov=0.09
... (1000 个 token)

平均值:
  S_hit_avg = 0.065
  S_attn_avg = 0.125
  S_cov_avg = 0.095

重要性分数:
  importance_score = 1.0×0.065 + 1.0×0.125 + 1.0×0.095
                   = 0.285
```

## 为什么这个方法有效？

### 核心逻辑链

```
1. 假设: 重要 head → 生成单词时关注对应音频区域
         │
         ▼
2. 验证: 检查注意力是否真的关注了对应区域
         │
         ▼
3. 量化: 计算三个指标（hit, attn, cov）
         │
         ▼
4. 聚合: 在所有单词 token 上平均
         │
         ▼
5. 排序: 按重要性分数排序
         │
         ▼
6. 结论: 分数高的 head = 重要的 head
```

### 统计显著性

```
单个样本: 可能偶然匹配
    ↓
多个样本: 排除偶然性
    ↓
大量单词: 发现稳定模式
    ↓
统计平均: 量化重要性
```

## 与其他方法的对比

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **本方法** | 基于对齐验证 | 直观、可解释、不需要扰动模型 | 依赖外部对齐质量 |
| 梯度方法 | 基于梯度大小 | 直接反映参数重要性 | 计算量大、可能不稳定 |
| 扰动方法 | 基于性能下降 | 直接测量影响 | 需要多次推理、计算成本高 |
| 激活分析 | 基于激活值 | 简单快速 | 难以解释因果关系 |
